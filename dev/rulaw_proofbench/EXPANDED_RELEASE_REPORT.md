- Все 525 эталонов принимаются scorer; выводы пересчитаны и совпали.
- Сверены рендеринг open/MCQ, буквы ответов, источники, модели проверок и типы условий.
- Проверены 2937 полных состояний и 9532 состояния с неизвестными фактами.
- Нет дубликатов IDs/нормализованных вопросов или пересечений нормативных
  зависимостей test со всем опубликованным train.
- Аудит фактических запросов: 652 активных (646 `gpt-6.1-sol`, 6 `gpt-6-astra`),
  34 исторических кешированных запроса учтены отдельно; effort `high`.
- Офлайн replay без сети воспроизвёл 505 test + 20 train, 2509 файлов без изменений.
- Четыре Parquet прошли обратное чтение и загрузку через закреплённый manifest
  в API-образе без torch/vLLM. Open/MCQ имеют одни и те же IDs.
- 63 builder-, 16 expanded-, 4 paired-report-, 3 expanded-task- и 14 legacy-task
  теста прошли. Dependency-free regressions: 0 failures. Compileall и diff check прошли.

Это проверки согласованности и исполнения; независимой экспертной юридической
валидацией они не являются. Исторические результаты не переносятся на новый test.

## Контекст и реальная оценка

На закреплённых токенизаторах Qwen3.5-2B Base/Instruct проверены все 505 случаев
во всех четырёх форматах с k=5: максимум 8024 токена, плюс резерв ответа 96
для open или 1 для MCQ. Контекст 16000, thinking выключен; это отдельная
проверка токенизации без inference.

HF smoke завершён: Instruct open 0-shot и Base MCQ 5-shot, closed/grounded,
по два случая на задачу (4 totals / 8 выполнений). Эти короткие проверки
не являются оценкой качества корпуса. API smoke тоже прошёл: Instruct open
и MCQ 0-shot, closed/grounded, по два случая (ещё 4 totals / 8 выполнений).
Клиент работал в CPU-only API-образе без torch/vLLM, сервер — локальный vLLM
с тем же закреплённым Instruct-снимком. Это проверка генерации и вероятностей,
не заявление о полной численной эквивалентности backend'ов. Временный сервер
остановлен после проверки. Итого smokes: 8 totals / 16 выполнений.

Полный vLLM-прогон завершён: 6 totals / 3030 выполнений, все 505 случаев
в каждой постановке; результаты scorer повторно вычислены и совпали.
Модели Qwen3.5-2B и Qwen3.5-2B-Base, thinking выключен, temperature 0.

| Модель и формат | Shot | Без контекста, macro / micro | С контекстом, macro / micro |
| --- | ---: | ---: | ---: |
| Base MCQ | 5 | 47,99% / 41,78% | 52,30% / 44,75% |
| Instruct open | 0 | 35,12% / 33,27% | 52,18% / 47,13% |
| Instruct MCQ | 0 | 28,49% / 30,89% | 34,26% / 33,27% |

Macro — средняя accuracy по 71 статье, micro — по 505 случаям. Эти числа
не доказывают превосходство Base над Instruct: форматы ответа и число
демонстраций различаются. Результаты относятся только к указанным моделям,
снимкам, режимам и этому набору; корпус по ним не отбирался и не исправлялся.

Парные изменения macro при добавлении контекста (10000 bootstrap-повторов,
seed 555; интервалы 95%, в процентных пунктах):

| Постановка | Изменение | По статьям | По компонентам общих норм |
| --- | ---: | ---: | ---: |
| Base MCQ | +4,31 | −0,55…+9,13 | −1,01…+9,27 |
| Instruct open | +17,07 | +10,20…+24,19 | +10,46…+24,30 |
| Instruct MCQ | +5,77 | +0,19…+11,91 | −0,51…+12,69 |

71 статья образует 52 компоненты общих нормативных зависимостей. При их
объединении сохраняются веса статей. Для Base MCQ оба интервала включают ноль;
для Instruct MCQ вывод чувствителен к учёту зависимостей. Оценка Instruct open
положительна при обоих способах группировки в рамках данного корпуса.

Окружение: RTX 4090, torch 2.11.0+cu129, CUDA 12.9, Transformers 5.9.0,

## Файлы и запуск

Корень артефактов: `dev/rulaw_artifacts/expanded-2026-10-12/`.

- `release-505/`: README и четыре Parquet, готовые для локальной оценки.
- `release-505-build/`: test/train JSONL, формализации, проверки, перечень старых случаев.
- `release-505-{validation,payload-validation,replay-validation,context-validation}.json`:
  результаты проверок.
- `accepted-test-505.json`: точный перечень принятых автором test IDs.
- `validation/`: реальные результаты и журналы backend-прогонов.
- `release-505-full-results.json`: сводка шести полных постановок.
- `release-505-smoke-results.json`: сводка восьми HF/API smoke-постановок.
- `release-505-*-grounding-paired.json`: парные оценки closed/grounded.

Конфиг построения — `configs/expanded-505.json`. Manifest —
`llmtf/tasks/rulaw_proofbench/manifest_expanded.json`. Для запуска выберите явные задачи
`rulaw_proofbench_expanded/{closed,grounded,mcq_closed,mcq_grounded}`.
Данные автоматически загружаются с HF по закреплённой ревизии; для локального
чтения можно задать `RULAW_EXPANDED_DATA_DIR` с путём к `release-505`.
Они поддерживают k=0/5; старые IDs и общие legal YAML по-прежнему используют
прежний опубликованный выпуск.
